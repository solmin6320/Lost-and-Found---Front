# 레퍼런스 조사

실제 서비스와 최신 UX 연구를 보고 우리 설계에 반영한 것. **2026-09-23 조사.**

무엇을 봤고, 무엇을 가져왔고, **무엇을 일부러 버렸는지** 남긴다. 나중에 "왜 이렇게 했지?"에 답하기 위해서다.

---

## 1. 당근 (daangn.com) — 목록·필터

직접 접속해 데스크톱과 모바일(375px)에서 확인했다. 중고거래는 우리와 **구조가 거의 같은 문제**를 푼다 — 썸네일 카드 목록, 거래 상태(판매중·예약중·거래완료), 지역·시간, 필터.

### 관찰

| | 당근 | 비고 |
|---|---|---|
| 모바일 375px | **2열 그리드** | 1열이 아니다 |
| 썸네일 | **정사각형 고정** | 세로 사진이 와도 카드 높이가 일정 |
| 정보 순서 | 썸네일 → 제목 → **가격(굵게)** → 지역·시간(회색) | 가격이 시선 2순위 |
| 필터 | 칩 버튼 2개(`필터`, `지역 선택`)만 노출 | 누르면 시트가 열린다 |
| 검색 | 상단 고정 입력창 | 필터보다 위 |
| 제목 | 1~2줄 말줄임 | 카드 높이가 절대 흔들리지 않는다 |

### 가져온 것

- **375px에서 2열로 간다.** 이 서비스도 "내 물건인가"를 썸네일로 판단하므로, 한 화면에 카드가 많이 보이는 쪽이 유리하다
- **썸네일 정사각형 고정.** 카드 높이가 흔들리면 스캔이 깨진다
- **필터는 칩 버튼 → 바텀시트.** 모바일에서 필터를 펼쳐두면 목록이 밀린다
- 당근의 **가격 자리**가 우리에게는 **장소 · 분실습득일**이다. 굵게 쓰는 대신 유형 배지가 그 역할을 한다

### 버린 것

- **가격처럼 굵은 강조를 장소에 주지 않는다.** 우리 화면에서 가장 강한 신호는 **유형 배지**여야 한다. 장소까지 굵게 하면 시선이 갈라진다
- 카테고리 가로 스크롤 탭 — 우리 카테고리는 5개뿐이라 필터 시트 안에 두는 편이 낫다

## 2. 필터 UX 연구

여러 2026년 가이드가 같은 결론을 낸다.

### 가져온 것

- **활성 필터를 칩으로 목록 위에 노출**한다. 각 칩에 `×`, 그리고 **`전체 해제`를 항상 둔다.** 필터를 걸어둔 걸 잊고 "왜 결과가 없지" 하는 상황이 가장 흔한 실패다
- **칩 라벨에 필드 이름을 넣는다.** `지갑` 이 아니라 **`카테고리: 지갑`**.
  우리는 특히 중요하다 — 검색어에도 "지갑"을 넣을 수 있어서, 라벨이 없으면 지금 걸린 게 검색어인지 카테고리인지 구분이 안 된다
- 같은 필드 안은 OR, 다른 필드끼리는 AND. 백엔드 `[4.2]` QueryDSL 구현과 일치한다
- 결과 개수를 필터 근처에 보여준다. "12건" 이 보이면 조건을 더 좁힐지 판단할 수 있다

### 우리 상황에 맞게 바꾼 것

- 연구는 "필터 적용 전 예상 결과 수 미리보기"를 권하지만, 백엔드에 그 API가 없다. **만들지 않는다.** 적용 후 개수만 보여준다

## 3. 온보딩 — 숫자가 설계를 바꿨다

조사에서 나온 수치가 우리가 잡은 방향을 확인해줬고, 한 군데는 바꾸게 했다.

| 발견 | 출처 정리 |
|---|---|
| **완주율은 5단계를 넘으면 급락한다.** 2~6카드는 33%가 끝까지 보지만, 7~11카드는 그 절반 이하 | 우리 3단계 유지가 맞다 |
| **사용자가 직접 눌러서 보는 안내는 자동 실행 투어보다 완주율이 123% 높다** | ⭐ 가장 중요한 발견 |
| 잘 만든 투어 완주율 61%, 못 만든 것 16% | 편차가 크다 = 설계가 결과를 가른다 |
| 완주한 사용자는 활성 사용자가 될 확률 2.5배 | 투어 자체는 가치가 있다 |
| 대부분의 신규 사용자는 코치마크를 스킵한다 | 스킵을 막으면 안 된다 |

### 이것 때문에 바꾼 것

`docs/온보딩설계.md` 의 **2층(맥락 안내)을 1층(순차 투어)보다 중요하게** 둔 판단이 데이터로 뒷받침됐다. 자동으로 뜨는 투어보다 **사용자가 그 기능 앞에서 스스로 여는 안내**가 두 배 이상 잘 작동한다.

그래서 추가한다.

- **헤더에 `서비스 안내`를 상시 노출**한다. 투어를 다시 볼 수 있는 입구를 숨기지 않는다
- 유형 배지에 **툴팁(누르면 설명)** 을 단다. 자동으로 뜨지 않고, 궁금한 사람이 누른다
- 1층 투어는 **3단계 고정.** 기능이 늘어도 단계를 늘리지 않는다
